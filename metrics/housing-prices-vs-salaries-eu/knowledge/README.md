# Project Knowledge

This folder is the project's cumulative memory.

Use it for findings, caveats, source quirks, methodological decisions, validation notes, visual inspection notes, and anything else future-us will be annoyed to rediscover.

## Files

- `caveats.md`: known limitations, missing data, comparability issues, and interpretation warnings.
- `findings.md`: researched facts, source behavior, formula confirmations, and decisions made during analysis.

## Rules

- Add findings as they happen.
- Date entries when the timing matters.
- Cite source URLs or exact API queries whenever possible.
- Prefer short, factual entries over prose essays.
- Never delete old findings just because they became inconvenient. Amend them with newer context.
